# Monitoramento de leiloes online

Sistema independente para monitorar leiloes online, normalizar lotes, manter historico, aplicar filtros e enviar notificacoes por Telegram e e-mail.

Este repositório contém o painel web, a API em Python, o coletor Freitas Leiloeiro, as regras de oportunidades, a análise opcional por IA e a configuração de deploy no Render.

Consulte `render.yaml` para a configuração de produção. Chaves e credenciais devem ser configuradas como variáveis privadas no serviço, nunca commitadas no repositório.
